# Living Tamil California website — Change log

Every change to the live site gets a new version here. Newest at the top.
Version numbers: MAJOR.MINOR.PATCH
- PATCH (1.0.1): wording fix, typo, photo swap
- MINOR (1.1.0): new page, new section, new program or event
- MAJOR (2.0.0): redesign or new hosting
