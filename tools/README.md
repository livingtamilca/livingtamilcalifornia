# tools/
Optional. Only needed to regenerate pages; the site works without them.

- make_readings_v2.py — rebuilds readings.html (Reading Archive) from the story/writer lists
  inside the script. Edit the lists, then run: `python3 make_readings_v2.py` from the
  folder that contains livingtamil-website/.
- writers_v3.py — adds the writers' portrait ribbon to every page except Home.

The Apps Script backends (forms, YouTube feed, donation logger) are kept in the
org Google account, inside their sheets/projects, not here.
